## About The Project
This is a simple Java project for managing employees in a department, based on the required UML diagram. 

It covers basic OOP concepts:
- Abstract `Employee` base class.
- Subclasses: `MonthlyEmployee`, `HourlyEmployee`, and `CommissionEmployee` each with their own salary logic.
- `Department` class to hold the list of employees, print them, and calculate the total payroll.
- `Gender` enum for male/female values.

## How to Run
- Just open the project in VS Code.
- Go to `src/test/MainTest.java`.
- Run the file to see the output and sample calculations in the terminal.
